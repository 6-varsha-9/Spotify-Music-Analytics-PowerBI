Spotify Music Analytics Dashboard 🎵

Interactive Spotify Analytics Dashboard built in Power BI using DAX and data visualization techniques. The project analyzes song popularity, artist performance, album trends, explicit content insights, and yearly music trends through KPI cards, charts, and dynamic dashboards.

- DAX
- Power Query
- Excel / CSV

Business Insights
- Taylor Swift has the highest number of songs in the dataset.
- Explicit songs show higher average popularity.
- Singles dominate Spotify chart rankings.
- Most tracks fall within the 2–4 minute duration range.
